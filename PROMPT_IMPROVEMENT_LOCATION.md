# 📍 Улучшение промпта: Извлечение локации из вложений

## Добавить в раздел "🏢 ОРГАНИЗАЦИИ (organizations)"

После пункта 8 (телефоны) добавить:

```
9. 📍 **ГОРОД И АДРЕС из вложений — КРИТИЧЕСКИ ВАЖНО:**
   - При анализе вложений (коммерческие предложения, реквизиты, счета и другие) **определи организации-участники**:
     * **Отправитель документа** — обычно в шапке документа (верхняя часть, логотип, реквизиты)
     * **Получатель документа** — обычно после шапки (блок "Кому:", "Компания:", адресат)
     * **Конечный пользователь** — если указан отдельно (блок "Конечный пользователь:", "Заказчик:")
   
   - **ПРАВИЛО ПРИНАДЛЕЖНОСТИ ГОРОДА И АДРЕСА:**
     * Город и адрес в шапке документа → ТОЛЬКО организация-отправитель
     * Город и адрес в блоке "Кому:" → ТОЛЬКО организация-получатель
     * Город и адрес в блоке "Конечный пользователь:" → ТОЛЬКО конечный пользователь
     * ❌ **НЕ присваивай** город/адрес отправителя → получателю
     * ❌ **НЕ присваивай** город/адрес из шапки → всем организациям в документе
     * ✅ **Город без адреса** - тоже важен! Если указан "г. Москва, Компания МИЛЛАБ" → city="Москва" для МИЛЛАБ
   
   - **Пример правильного извлечения:**
     ```
     Шапка документа:
     ООО "ДНК-Технология"
     Адрес: 117587, г. Москва, Варшавское шоссе, д. 125Ж...
     
     Кому:
     Компания МИЛЛАБ
     Акутину Ивану Алексеевичу
     
     Конечный пользователь:
     ФБУЗ "Центр Гигиены и Эпидемиологии в Республике Хакасия"
     г. Абакан
     
     ✅ ПРАВИЛЬНО:
     - ДНК-Технология: city="Москва", address="117587, г. Москва, Варшавское шоссе, д. 125Ж..."
     - МИЛЛАБ: city=null, address=null (адрес не указан для МИЛЛАБ в документе)
     - ФБУЗ: city="Абакан", address=null (указан только город)
     
     ❌ НЕПРАВИЛЬНО:
     - МИЛЛАБ: address="117587, г. Москва..." (это адрес ДНК-Технология!)
     - ФБУЗ: address="117587" (это адрес ДНК-Технология!)
     ```
   
   - **Признаки принадлежности адреса:**
     * Адрес находится в том же блоке, что и название организации
     * Адрес следует сразу после названия организации (в пределах 2-3 строк)
     * Адрес предваряется меткой "Адрес:", "Юридический адрес:", "Местонахождение:"
     * Адрес находится в шапке документа (верхние 10-15 строк) → отправитель
   
   - **Признаки НЕпринадлежности адреса:**
     * Адрес находится в другом блоке документа
     * Между организацией и адресом есть другая организация
     * Адрес находится в шапке, а организация упоминается в теле документа
   
   - **Если не уверен** в принадлежности адреса → оставь `city: null, address: null`
   - **Лучше пропустить**, чем присвоить чужой адрес
```

## Добавить в раздел "📋 ПРАВИЛА ИЗВЛЕЧЕНИЯ" (в начало)

```
⚠️ **КРИТИЧЕСКИ ВАЖНО для адресов из вложений:**
- Адрес в шапке документа принадлежит ТОЛЬКО организации-отправителю
- НЕ копируй адрес из шапки другим организациям, упомянутым в документе
- Если адрес организации не указан явно в её блоке → city=null, address=null
- Индекс без города и улицы (например, "117587") → НЕ является полным адресом
```

## Добавить примеры в конец промпта

```
📍 **ПРИМЕРЫ ИЗВЛЕЧЕНИЯ ЛОКАЦИИ ИЗ ВЛОЖЕНИЙ:**

Пример 1: Коммерческое предложение
```
Шапка:
ООО "Поставщик"
Адрес: 123456, г. Санкт-Петербург, ул. Ленина, д. 1

Кому: ООО "Покупатель"
Тел: +7 (495) 123-45-67

Конечный пользователь: ФБУЗ "Больница", г. Казань
```

Результат:
- Поставщик: city="Санкт-Петербург", address="123456, г. Санкт-Петербург, ул. Ленина, д. 1"
- Покупатель: city=null, address=null (адрес не указан)
- ФБУЗ "Больница": city="Казань", address=null (указан только город)

Пример 2: Реквизиты
```
ООО "Компания А"
ИНН: 1234567890
Юридический адрес: 654321, г. Москва, ул. Тверская, д. 10

Банковские реквизиты:
Р/с: 40702810...
```

Результат:
- Компания А: city="Москва", address="654321, г. Москва, ул. Тверская, д. 10"

Пример 3: Письмо с упоминанием нескольких организаций
```
От: ООО "Дистрибьютор", Москва, Варшавское ш., 125

Добрый день!
Направляем КП для Компании МИЛЛАБ.
Конечный пользователь: Центр в г. Абакан.
```

Результат:
- Дистрибьютор: city="Москва", address="Москва, Варшавское ш., 125"
- МИЛЛАБ: city=null, address=null (адрес не указан)
- Центр: city="Абакан", address=null (указан только город)
```
