# 🔒 Настройка приватности OpenRouter для бесплатных моделей

## Проблема

При использовании бесплатных моделей на OpenRouter (например, `deepseek/deepseek-chat-v3.1:free`) может возникать ошибка:

```
❌ OpenRouter data policy error: Provider returned error
```

Это происходит потому что бесплатные модели требуют согласия на публикацию промптов в публичные датасеты.

## Решение

### Шаг 1: Откройте настройки интеграций

Перейдите на страницу: https://openrouter.ai/settings/integrations

### Шаг 2: Включите публикацию промптов

Найдите настройку:

**"Enable free endpoints that may publish prompts"**

Описание: _Allow free model providers to publish your prompts and completions to public datasets._

✅ **Включите эту настройку** (поставьте галочку)

### Шаг 3: Сохраните изменения

После включения настройки изменения должны применитьсяавтоматически.

### Шаг 4: Проверьте работу

Запустите тестовый скрипт:

```bash
python test_openrouter_error.py
```

Если все настроено правильно, вы должны увидеть:

```
✅ Ответ получен успешно:
   Content: [ответ модели]
```

## Альтернативные решения

### Вариант 1: Использовать платные модели

Платные модели не требуют публикации промптов. Примеры:

- `deepseek/deepseek-chat-v3.1` (без `:free`)
- `anthropic/claude-3-sonnet`
- `openai/gpt-4`

Для этого нужно:
1. Добавить кредиты на аккаунт OpenRouter
2. Изменить модель в `config/models_config.yaml`

### Вариант 2: Использовать другие бесплатные модели

Некоторые бесплатные модели не требуют публикации:

- `google/gemini-2.0-flash-exp:free` (обычно не требует)
- `meta/llama-3.1-8b-instruct:free` (если доступна)

### Вариант 3: Использовать Replicate как основной провайдер

Replicate не требует публикации промптов. Измените приоритеты в `config/models_config.yaml`:

```yaml
openrouter:
  models:
    - name: "google/gemini-2.0-flash-exp:free"
      priority: 1
```

## Проверка текущих настроек

Чтобы проверить какие настройки у вас включены:

1. Откройте https://openrouter.ai/settings/integrations
2. Проверьте статус "Enable free endpoints that may publish prompts"
3. Если галочка снята - включите её

## Безопасность

⚠️ **Важно:** При включении публикации промптов ваши запросы к бесплатным моделям могут быть опубликованы в публичных датасетах.

**Не отправляйте через бесплатные модели:**
- Персональные данные (ПДн)
- Конфиденциальную информацию
- Коммерческую тайну
- Данные клиентов

**Для конфиденциальных данных используйте:**
- Платные модели OpenRouter (не публикуются)
- Локальные модели (Ollama)
- Собственные API ключи провайдеров

## Troubleshooting

### Ошибка продолжается после включения настройки

1. Подождите 1-2 минуты после изменения настроек
2. Очистите кэш браузера
3. Перезапустите приложение
4. Проверьте что используете правильный API ключ

### Модель недоступна

Если модель `deepseek/deepseek-chat-v3.1:free` недоступна:

1. Проверьте статус на https://openrouter.ai/models
2. Попробуйте другую бесплатную модель
3. Система автоматически переключится на следующую модель в списке

### Circuit Breaker открыт

Если видите ошибку "Circuit Breaker открыт":

```bash
python reset_openrouter_circuit_breaker.py
```

Это сбросит счетчик ошибок и разблокирует провайдер.
