# Email Fetcher v2.0 - CLI Интерфейс

## 🚀 Обзор

Новый CLI интерфейс для Email Fetcher v2.0 обеспечивает удобный запуск фетчера с интерактивным меню и поддержкой различных режимов работы.

## 📋 Установка и запуск

### Способ 1: Прямой запуск через CLI

```bash
# Интерактивный режим (рекомендуется)
python3 src/fetcher/cli.py --interactive

# Прямой запуск с параметрами
python3 src/fetcher/cli.py --date 2025-07-12
python3 src/fetcher/cli.py --start-date 2025-07-01 --end-date 2025-07-31

# Legacy режим
python3 src/fetcher/cli.py --interactive --legacy
```

### Способ 2: Быстрый запуск через скрипт

```bash
# Сделать скрипт исполняемым (один раз)
chmod +x run_new_fetcher.py

# Запуск с параметрами
./run_new_fetcher.py --date 2025-07-12
./run_new_fetcher.py --interactive
```

## 🎛️ Режимы работы

### 1. Интерактивный режим

Позволяет выбрать параметры через удобное меню:

```bash
python3 src/fetcher/cli.py --interactive
```

Меню предлагает варианты:
- Диапазон дат (от-до)
- Одна конкретная дата
- Весь месяц текущего года
- Последние 7 дней
- Последние 30 дней
- Тестовый запуск (сегодня)

### 🔄 Улучшенная обработка ошибок ввода

При ошибках ввода данных CLI предлагает:
- Подробное сообщение об ошибке
- Примеры правильных форматов
- Возможность повторить ввод
- Возврат в главное меню

### 2. Прямой запуск с датами

```bash
# Одна дата
python3 src/fetcher/cli.py --date 2025-07-12

# Диапазон дат
python3 src/fetcher/cli.py --start-date 2025-07-01 --end-date 2025-07-31
```

### 3. Legacy режим

Для обратной совместимости со старым кодом:

```bash
python3 src/fetcher/cli.py --interactive --legacy
```

## 📅 Форматы дат

CLI поддерживает множество форматов дат (полная совместимость со старым фетчером):

### ISO формат
- `2025-07-12`

### Формат с точками
- `12.07.2025`
- `7.7.25` (короткий формат)

### Короткий формат с дефисами
- `12-7-25`

### Русский текстовый формат
- `12 июля 25`
- `7 июля 2025`

### Примеры использования
```bash
# Все эти форматы работают:
python3 src/fetcher/cli.py --date 2025-07-12
python3 src/fetcher/cli.py --date "12.07.2025"
python3 src/fetcher/cli.py --date "12-7-25"
python3 src/fetcher/cli.py --date "12 июля 25"
python3 src/fetcher/cli.py --date "7.7.25"
```

## 🔧 Демонстрационный режим

Если некоторые зависимости отсутствуют, CLI автоматически переключается в демонстрационный режим:

```
❌ Ошибка импорта утилит дат: No module named 'structlog'
✅ Используем упрощенные утилиты дат для демонстрации

🎯 ДЕМО: Загрузка писем за период 2025-07-12 - 2025-07-12
✅ ДЕМО: Это демонстрационный режим для тестирования CLI
🔧 Для полноценной работы установите необходимые зависимости
```

## 📝 Логирование

CLI автоматически создает лог-файлы в папке `data/logs/`:

- Имя файла: `new_email_fetcher_YYYYMMDD_YYYYMMDD.log`
- Формат: временная метка, уровень, сообщение
- Дублируется в консоль для удобства

## ⚡ Оптимизации

1. **Fallback система**: При отсутствии зависимостей использует упрощенные версии
2. **Информативные сообщения**: Подробная информация о процессе
3. **Гибкие форматы дат**: Поддержка различных форматов ввода
4. **Автоматическое создание директорий**: Создает необходимые папки

## 🛠️ Устранение неполадок

### Ошибка: No module named 'structlog'

CLI автоматически переключается в демонстрационный режим. Для полноценной работы установите недостающие зависимости.

### Ошибка импорта компонентов

CLI использует fallback-механизмы и пробует альтернативные пути импорта.

### Проблемы с интерактивным режимом

В некоторых средах интерактивный ввод может не работать. Используйте прямые параметры:

```bash
python3 src/fetcher/cli.py --date 2025-07-12
```
