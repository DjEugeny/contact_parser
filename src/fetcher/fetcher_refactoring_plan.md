# План рефакторинга Advanced Email Fetcher

## 📋 Обзор

Текущий модуль `src/advanced_email_fetcher.py` представляет собой монолитный класс из 3035 строк, который выполняет множество функций. Для улучшения поддерживаемости, тестируемости и расширяемости предлагается разбить его на управляемые компоненты.

## 🎯 Цели рефакторинга

1. **Разделение ответственности** - каждый компонент отвечает за свою область
2. **Улучшение тестируемости** - изолированные компоненты легче тестировать
3. **Повышение поддерживаемости** - меньшие файлы легче понимать и изменять
4. **Упрощение расширения** - новую функциональность легче добавлять
5. **Сохранение обратной совместимости** - существующий API должен работать

## 📊 Компоненты и их ответственность

### 1. core/email_fetcher.py (Основной фасад)

**Ответственность**:
- Координация работы компонентов
- Предоставление публичного API
- Управление жизненным циклом

**Методы**:
- `fetch_emails_by_date_range()` - основная точка входа
- `process_single_email()` - обработка одного письма
- `close()` - завершение работы

**Размер**: ~200 строк

### 2. core/connection_manager.py

**Ответственность**:
- Управление IMAP соединением
- Обработка connection pooling
- Повторные подключения

**Методы**:
- `connect()` - установка соединения
- `disconnect()` - разрыв соединения
- `is_connected()` - проверка соединения
- `reconnect()` - переподключение

**Размер**: ~150 строк

### 3. core/email_processor.py

**Ответственность**:
- Обработка одного письма
- Координация парсинга и фильтрации
- Сохранение результатов

**Методы**:
- `process_email()` - основная обработка
- `apply_filters()` - применение фильтров
- `save_email()` - сохранение письма

**Размер**: ~300 строк

### 4. attachments/attachment_handler.py

**Ответственность**:
- Обработка вложений из письма
- Извлечение и сохранение файлов
- Фильтрация вложений

**Методы**:
- `extract_attachments()` - извлечение вложений
- `save_attachment()` - сохранение вложения
- `filter_attachment()` - фильтрация вложения

**Размер**: ~250 строк

### 5. attachments/attachment_registry.py

**Ответственность**:
- Регистрация вложений
- Поиск вложений по message_id
- Управление связями письмо-вложение

**Методы**:
- `register_attachment()` - регистрация вложения
- `get_attachments_by_message()` - получение вложений письма
- `cleanup_orphaned_attachments()` - очистка

**Размер**: ~200 строк

### 6. filters/email_filters.py

**Ответственность**:
- Применение фильтров к письмам
- Черные списки
- Фильтрация контента

**Методы**:
- `apply_filters()` - применение фильтров
- `is_subject_filtered()` - фильтр по теме
- `is_sender_blacklisted()` - фильтр по отправителю

**Размер**: ~200 строк

### 7. parsers/email_parser.py

**Ответственность**:
- Парсинг писем
- Извлечение заголовков
- Извлечение контента

**Методы**:
- `parse_email()` - парсинг письма
- `parse_headers()` - парсинг заголовков
- `extract_content()` - извлечение контента

**Размер**: ~250 строк

### 8. storage/email_storage.py

**Ответственность**:
- Сохранение писем
- Чтение писем
- Управление файловой структурой

**Методы**:
- `save_email()` - сохранение письма
- `load_email()` - загрузка письма
- `email_exists()` - проверка существования

**Размер**: ~200 строк

### 9. legacy/advanced_email_fetcher.py

**Ответственность**:
- Обратная совместимость
- Адаптация нового API к старому
- Плавный переход

**Методы**:
- Все методы оригинального класса
- Внутренняя делегация новым компонентам

**Размер**: ~150 строк
