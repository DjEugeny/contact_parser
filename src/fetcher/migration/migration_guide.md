# Руководство по миграции вложений из thread_id в message_id

## 🎯 Цель миграции

**Проблема:** В существующей системе вложения привязаны к `thread_id`, что приводит к некорректному маппингу - вложения из одного письма в треде ошибочно приписываются всем остальным письмам этого же треда.

**Решение:** Миграция вложений на привязку к `message_id` для точного соответствия вложений конкретным письмам.

## ⚠️ Возможные проблемы и решения

### Проблема 1: Осиротевшие вложения
**Симптом:** Вложения без соответствующих писем
**Решение:** Такие вложения остаются на месте, их нужно обработать вручную

### Проблема 2: Недостаточно прав доступа
**Симптом:** Ошибка при перемещении файлов
**Решение:** Запустите миграцию с правами суперпользователя или проверьте права доступа

### Проблема 3: Поврежденные JSON файлы
**Симптом:** Ошибка при чтении писем
**Решение:** Проверьте целостность JSON файлов перед миграцией

### Проблема 4: Нехватка места на диске
**Симптом:** Ошибка при создании бэкапа
**Решение:** Освободите место на диске или используйте внешнее хранилище для бэкапа
