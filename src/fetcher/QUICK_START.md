# 🚀 Быстрый старт с Email Fetcher v2.0

## 📋 Обзор

Новый модульный Email Fetcher v2.0 предоставляет исправленный маппинг вложений и улучшенную архитектуру. Теперь можно запускать его прямо из IDE с помощью CLI меню.

## 🎯 Способы запуска

### 1. Быстрый запуск из корня проекта (рекомендуется)

```bash
python3 run_new_fetcher.py
```

Этот скрипт автоматически:
- Активирует виртуальное окружение (.venv)
- Импортирует реальные компоненты
- Запускает интерактивное меню

### 2. Прямой запуск CLI

```bash
# С активацией виртуального окружения
source .venv/bin/activate
python3 src/fetcher/cli.py

# Или через запускчик (автоактивация)
python3 run_new_fetcher.py --interactive
```

### 3. Запуск с параметрами

```bash
# Одна конкретная дата
python3 run_new_fetcher.py --date "28-7-25"

# Диапазон дат
python3 run_new_fetcher.py --start-date "28-7-25" --end-date "29-7-25"

# Разные форматы дат
python3 run_new_fetcher.py --date "2025-07-28"     # ISO формат
python3 run_new_fetcher.py --date "28.07.2025"    # Точки
python3 run_new_fetcher.py --date "28 июля 25"    # Русский формат
```

## 📅 Поддерживаемые форматы дат

- `2025-07-12` (ISO формат)
- `12.07.2025` (точки)
- `12-7-25` (короткий формат)
- `12 июля 25` (текстовый формат на русском)
- `7.7.25` (короткий формат с точками)

## 🔧 Демонстрационный режим

Если некоторые зависимости отсутствуют, фетчер автоматически переключится в демо-режим с соответствующим уведомлением.

## 📁 Структура результатов

- `data/emails/` - сохраненные письма в JSON формате
- `data/attachments/` - вложения с привязкой к message_id
- `data/logs/` - логи обработки и статистика

## ⚠️ Важные замечания

1. **Virtual Environment**: Убедитесь, что виртуальное окружение `.venv` активировано
2. **Зависимости**: Основные зависимости (structlog) уже установлены
3. **Конфигурация**: Настройки IMAP соединения берутся из `.env` файла

## 🆘 Поиск проблем

Если фетчер не запускается:

1. Проверьте наличие виртуального окружения:
   ```bash
   ls -la .venv/
   ```

2. Активируйте окружение вручную:
   ```bash
   source .venv/bin/activate
   python3 run_new_fetcher.py --demo
   ```

3. Проверьте зависимости:
   ```bash
   source .venv/bin/activate
   pip install structlog
   ```
