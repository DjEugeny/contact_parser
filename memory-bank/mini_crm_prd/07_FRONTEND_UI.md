# 07_FRONTEND_UI — UX/UI (обновлено)

**Статус:** Draft v2

## A. Главный экран (Dashboard)
- Строка **поиска** (главная точка входа).  
- **Последние** добавленные/обновлённые контакты и организации.  
- **КП с истекающим сроком** (сортировка по близости `valid_until`).
- «Модерационный inbox» — сомнительные контакты/организации для ручной проверки.

## B. Список/поиск
- Фильтры: **город**, **организация/ИНН**, **email**, **телефон**, **ФИО**, по КП — конечный пользователь/посредник/статус/диапазон дат.  
- Сортировки: по алфавиту, по городу, по дате обновления.

## C. Карточка организации
- Блок «Основное»: название, сайт, адрес, ИНН.  
- Вкладки: **Контакты** | **История** (общая лента) | **КП**.  
- Быстрые действия: «Добавить заметку», «Сохранить фильтр» (вид).

## D. Карточка контакта
- Блок «Основное»: ФИО, должность, компания, телефоны (массив типов), email, город.  
- **Лента взаимодействий**: события по письмам/заметкам/звонкам; каждая запись содержит `role_in_message` и ссылку на исходник.  
- Связанные **КП** (кликом — переход к КП/исходным файлам).

## E. КП — реестр
- Таблица: номер, дата, организация(и) (конечный/посредник), сумма, статус, `valid_until`.  
- Фильтры/сортировки + быстрые действия (изменить статус, добавить напоминание).

## F. Просмотр исходного письма (дружественный UX)
- **Открыть письмо** — основное действие для пользователя. Алгоритм:
  1) если сохранён `.eml` — открыть его в системном почтовом клиенте;
  2) если `.eml` нет — показать встроенный просмотрщик письма в CRM (текст из JSON + список вложений);
  3) доп. возможность «Скопировать тему/отправителя» для ручного поиска.
- **Дополнительно (для администратора в меню «⋯»):**
  - Скачать `.eml` (если сохранён);
  - Скачать JSON письма (для отладки);
  - Показать `Message‑ID`.

## G. Мобильный доступ
- **PWA**: офлайн‑кеш для UI и метаданных; работа «read‑only» при отсутствии сети (без запуска конвейера).
