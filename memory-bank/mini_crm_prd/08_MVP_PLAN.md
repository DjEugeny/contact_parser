## Фаза 1 — Тестовый конвейер (MVP 0.5)
- Подготовить **api_pipeline_validator.py** как сквозной тест‑раннер:  
  1) загрузка писем (reuse существующего fetcher с фильтрами),  
  2) OCR (reuse существующего модуля),  
  3) вызов LLM (обновлённый промпт),  
  4) **валидация/нормализация/дедуп/обогащение**,  
  5) запись в **PostgreSQL (Supabase)**.  
- Режимы: `--first10`, `--batch 20`, `--date 2025-05-05`, поддержка нескольких дат.
- Выходы: PostgreSQL БД, логи, сохранение сырого JSON LLM в `data/llm_results/…`, отчёты по каждому письму в формате *.md для быстрого просмотра результатов.
