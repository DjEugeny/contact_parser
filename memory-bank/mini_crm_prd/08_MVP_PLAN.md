# 08_MVP_PLAN — План MVP (обновлено)

**Крайняя желаемая дата демонстрации:** 2025‑10‑07  
**Статус модулей:** Импорт/фильтрация и OCR — **уже реализованы** (переиспользуем).

## Фаза 1 — Тестовый конвейер (MVP 0.5)
- Подготовить **api_pipeline_validator.py** как сквозной тест‑раннер:  
  1) загрузка писем (reuse существующего fetcher с фильтрами),  
  2) OCR (reuse существующего модуля),  
  3) вызов LLM (обновлённый промпт),  
  4) **валидация/нормализация/дедуп/обогащение**,  
  5) запись в **SQLite `crm.db`**.  
- Режимы: `--first10`, `--batch 20`, `--date 2025-05-05`, поддержка нескольких дат.
- Выходы: `crm.db`, логи, сохранение сырого JSON LLM в `data/llm_results/…`, отчёты по каждому письму в формате *.md для быстрого просмотра результатов.

## Фаза 2 — Google Sheets (MVP 1.0)
- Экспорт в табличную форму: **Контакты / Организации / КП / История / Inbox**.  
- Колонки с ссылками на файлы (.eml если есть, JSON всегда).

## Фаза 3 — Веб‑приложение (MVP 1.5)
- **Backend FastAPI** (поиск/карточки/реестр КП/заметки).  
- **Frontend React (PWA)** — экраны из `07_FRONTEND_UI.md`.  
- Уведомления по истекающим КП внутри UI.

## Фаза 4 — Рефакторинг и оптимизация (Post‑MVP)

- Асинхронные вызовы LLM, кэширование, параллельная обработка.
