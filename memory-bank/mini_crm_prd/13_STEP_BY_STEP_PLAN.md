# STEP_BY_STEP_PLAN — Шаги реализации (синхронизировано)

## Шаг 0. Подготовка окружения
- Проверить .env и доступы IMAP/LLM/Vision/Sheets.  
- Создать `crm.db` миграцией.

## Шаг 1. Тестовый раннер (api_pipeline_validator.py)
- Подключить существующие fetcher+OCR.  
- Встроить LLM‑вызов с **обновлённым промптом**.  
- Реализовать валидатор/нормализацию/дедуп/обогащение.  
- Писать в SQLite + отчёт Inbox.

## Шаг 2. Экспорт в Google Sheets (интерим)
- Скрипт экспорта: 4–5 листов, ссылки на JSON/.eml/attachments.  
- Ручная верификация качества и корректировок промпта.

## Шаг 3. Backend + Frontend (MVP)
- FastAPI + React (PWA): search, карточки, реестр КП, уведомления.  
- Модерационный inbox в UI.

## Шаг 4. Автоматизация и перенос на VPS
- CRON для ежедневного запуска конвейера.  
- Docker + Nginx.  
- Бэкапы `crm.db` и каталога данных.
