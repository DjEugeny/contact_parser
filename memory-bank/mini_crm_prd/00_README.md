# mini-CRM PRD — пакет документов

Дата: 2025-09-27

Этот пакет содержит согласованный черновик PRD, техническое задание и план работ для мини‑CRM,
собирающей контакты, организации и коммерческие предложения (КП) из корпоративной почты (IMAP),
с промежуточным выводом в таблицы и дальнейшим запуском веб‑приложения (PWA).

## Структура
- `01_PRD_OVERVIEW.md` — цели, контекст, метрики, границы MVP.
- `02_REQUIREMENTS.md` — функциональные/нефункциональные требования.
- `03_SYSTEM_ARCHITECTURE.md` — архитектура, компоненты, пайплайн импорт→OCR→LLM→нормализация.
- `04_DATA_MODEL.md` — схема данных (MySQL), связи, индексы.
- `05_PARSING_AND_DEDUP.md` — извлечение, валидация, дедупликация, модерация.
- `06_SEARCH_AND_INDEXING.md` — мультикритериальный поиск, индексация, сохранённые фильтры.
- `07_FRONTEND_UI.md` — экраны, карточки, дашборд, PWA-поведение.
- `08_MVP_PLAN.md` — фазы, дорожная карта до 7 октября, критерии приёмки.
- `09_PROMPTS_AND_VALIDATION.md` — промпты, строгий JSON, JSON Schema, примеры.
- `10_GOOGLE_SHEETS_INTERIM.md` — временное решение на Google/локальных таблицах.
- `11_RISKS_AND_ASSUMPTIONS.md` — риски, допущения и планы смягчения.
- `12_API_CONTRACTS.md` — контракты REST/HTTP для фронтенда (минимально достаточные).
- `13_STEP_BY_STEP_PLAN.md` — план работ, фазы, сроки, задачи.
- `14_TECHNICAL_SPECIFICATION.md` — архитектурный дизайн, стек, схема БД, API, конвейер.
- `15_DB_MIGRATION_SAFE_SCHEMA.md` — правила миграции БД с MySQL на PostgreSQL.

> Формат — Markdown. Готово к использованию в Visual Studio Code и для работы с AI‑агентами.
