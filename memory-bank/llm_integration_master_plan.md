## 📋 Обзор и Цели

### 🎯 Основная Задача
Реализовать полноценную систему извлечения структурированных данных из email-писем с использованием LLM, включающую:
1. **Извлечение контактов** - полная информация о контактных лицах
2. **Саммари писем** - бизнес-контекст и ключевые аспекты взаимодействия  
3. **Коммерческие предложения** - структурированные данные по КП и ценам

### 🔄 Архитектурная Цепочка
```
Email → OCR → LLM Extractor → Integrated Processor → Google Sheets Bridge → Google Sheets
```
