# Отчет: Отладка извлечения ИНН и сайтов из LLM

## Проблема
В ходе тестирования было обнаружено, что система показывала 0% эффективность извлечения ИНН и сайтов из электронных писем.

## Процесс отладки

### 1. Анализ исходных данных
- Проверен тестовый файл: `email_025_20250729_20250729_dna-technology_ru_4aee22c5.json`
- ИНН `1901066506` найден на позиции 841 в исходном тексте
- Сайт `https://fgis.gost.ru/` найден на позиции 1248 в исходном тексте

### 2. Создание отладочного теста
- Создан тест `tests/test_debug_llm_input.py` для перехвата данных, передаваемых в LLM
- Тест показал, что данные корректно передаются в LLM:
  - Длина текста: 4400+ символов
  - ИНН и сайт присутствуют в LLM-тексте

### 3. Обнаружение корневой причины
**ПРОБЛЕМА**: Система работала в тестовом режиме (`test_mode=True`), который:
- Пропускает реальные LLM запросы
- Возвращает заглушки вместо реальных результатов
- Показывает сообщение: "🧪 ТЕСТОВЫЙ РЕЖИМ: Пропускаем LLM запросы"

### 4. Решение
- Отключен тестовый режим (`test_mode=False`)
- Проведен повторный тест с реальными LLM запросами
