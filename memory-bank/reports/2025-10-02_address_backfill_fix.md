# Отчёт об исправлении: Проблема с адресами HQ у контактов в разных городах

**Дата:** 2025-10-02  
**Автор:** AI Assistant (Kilo Code)  
**Версия кода:** После коммита с исправлением в `data_enricher.py`

---

## 📋 Краткое описание проблемы

При обработке писем из архива обнаружено, что адрес головного офиса организации (Москва, "Варшавское шоссе, дом 125Ж, корпус 6, этаж 5") некорректно присваивался контактам, работающим в других городах:

- **Воронова Светлана** (город: Новосибирск) ← получала адрес Москвы
- **Суржикова Галина** (город: Новокузнецк) ← получала адрес Москвы  
- **Клочкова-Абельянц Сатеник** (город: Москва) ← корректно получала адрес Москвы

## 🔍 Анализ причины

### Последовательность обработки данных

1. **LLM extraction** → контакты извлекаются из писем
2. **PostProcessor.process_llm_response()**:
   - `_backfill_contact_city_address()` → заполняет пустые города/адреса из организации (управляемо)
   - `_scrub_contact_addresses()` → удаляет адреса, совпадающие с HQ
   - ✅ После этих шагов адреса очищены
3. **Обогащение данных:**
   - `_enrich_contact_data()` → вызывает enricher'ы
   - `SmartContactEnricher.enrich_contacts()` → обогащает сайтами
   - **❌ `DataEnricher.enrich_contacts()` → БЕЗУСЛОВНО копирует адрес организации!**

### Проблемный код

В файле [`src/postprocessing/data_enricher.py`](../../src/postprocessing/data_enricher.py) метод `_enrich_location_from_organization()` (строки 148-155):

```python
# СТАРАЯ ЛОГИКА (проблемная)
if not contact.get('address') and organization.get('address'):
    contact['address'] = organization['address']  # ❌ Копирует БЕЗ проверки города!
```

Этот код выполнялся **ПОСЛЕ** очистки адресов, поэтому HQ адрес всё равно попадал к региональным представителям.

## ✅ Решение

Изменена логика в методе `_enrich_location_from_organization()`:

### Новый алгоритм

Адрес организации копируется в контакт **ТОЛЬКО** если:
1. У контакта нет собственного адреса (как и раньше)
2. **И** город контакта совпадает с городом организации (новое условие!)

### Реализация

```python
# НОВАЯ ЛОГИКА (исправленная)
if not contact.get('address') and organization.get('address'):
    contact_city = contact.get('city', '').strip().lower() if contact.get('city') else ''
    org_city = organization.get('city', '').strip().lower() if organization.get('city') else ''
    
    # Копируем адрес только если города совпадают
    if contact_city and org_city and contact_city == org_city:
        contact['address'] = organization['address']
        self.logger.debug(
            f"Обогащен address для контакта {contact.get('name', 'Unknown')}: "
            f"{organization['address']} (город совпадает: {contact_city})"
        )
    elif contact_city and org_city and contact_city != org_city:
        self.logger.debug(
            f"Адрес НЕ обогащен для контакта {contact.get('name', 'Unknown')}: "
            f"город контакта ({contact_city}) отличается от города организации ({org_city})"
        )
```
