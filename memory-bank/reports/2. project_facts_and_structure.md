## 🎯 Ключевые факты проекта

### Общая информация:
- **Название:** Contact Parser
- **Тип:** Система автоматизированного извлечения контактов
- **Язык:** Python 3.x
- **Архитектура:** Слоистая модульная архитектура (Core, Services, Configuration, Postprocessing)
- **Основная цель:** Извлечение и нормализация контактной информации из email-писем и вложений
- **Текущая фаза:** Фаза 5 (Унифицированная архитектура с постобработкой)

### Технологический стек:
- **Backend:** Python 3.x
- **OCR:** Google Cloud Vision API
- **LLM:** OpenRouter, Groq, Replicate
- **Email:** IMAP протокол
- **Export:** Google Sheets API
- **Data Storage:** JSON файлы, локальная файловая система
- **Configuration:** Унифицированный менеджер конфигурации
- **Postprocessing:** Система нормализации и дедупликации данных

### Ключевые возможности:
- ✅ Загрузка писем с IMAP серверов
- ✅ OCR обработка изображений и документов
- ✅ LLM анализ для извлечения контактов
- ✅ Экспорт в Google Sheets
- ✅ Система фильтрации спама
- ✅ Обработка множественных форматов файлов
- ✅ Rate limiting и fallback механизмы
- ✅ Постобработка и нормализация данных
- ✅ Дедупликация контактов и организаций
- ✅ Фильтрация и обогащение данных
- ✅ Унифицированная система конфигурации

### Статистика кода:
- **Основных модулей:** 7
- **Строк кода в ключевых файлах:**
  - `advanced_email_fetcher.py`: 2079 строк
  - `google_sheets_exporter.py`: 702 строки

### 📦 Legacy Modules - Устаревшие модули (Фаза 12)

#### 1. `advanced_email_fetcher.py` (2079 строк)
**Статус:** Требует рефакторинга в Фазе 12
**Назначение:** Первичная загрузка писем с IMAP сервера

**Ключевые классы:**

- Подключение к IMAP серверу
- Загрузка писем за диапазон дат
- Скачивание и сохранение вложений

- Обработка больших файлов

**Поддерживаемые форматы вложений:**
- Документы: PDF, DOC, DOCX, TXT

- **Google Cloud Vision** - основной OCR движок

- **python-docx** - обработка DOCX
- **openpyxl/xlrd** - чтение Excel файлов

**Возможности:**
- Умное сжатие изображений
- Обработка больших файлов
- Нормализация имен файлов
- Кэширование результатов

## 🚀 Развертывание

### Требования к системе:
- Python 3.8+
- Доступ к интернету
- Google Cloud Vision API
- Google Sheets API
- IMAP доступ к почтовому серверу

### Шаги установки:
1. Клонирование репозитория
2. Установка зависимостей: `pip install -r requirements.txt`
3. Настройка `.env` файла
4. Настройка Google API ключей
5. Запуск: `python src/google_sheets_exporter.py`

## 🔄 Пайплайн обработки данных (Фаза 5)

### Основной поток:
```
1. Email Fetching (advanced_email_fetcher.py)
   ↓
2. OCR Processing (ocr_processor.py) 
   ↓
3. LLM Analysis (integrated_llm_processor.py)
   ↓
4. Postprocessing Pipeline:
   - Data Normalization (normalizer.py)
   - Contact Deduplication (deduplicator.py)
   - Organization Detection (organization_detector.py)
   - Commercial Offer Filtering (commercial_offer_filter.py)
   - Data Enrichment (enricher.py)
   ↓
5. Export (google_sheets_exporter.py)
   ↓
6. Report Generation (report_generator.py)
```

### Взаимосвязи модулей:
- **Configuration Layer** → управляет всеми компонентами
- **Core Layer** → обеспечивает базовую функциональность
- **Services Layer** → выполняет основную обработку
- **Postprocessing Layer** → улучшает качество данных
- **Legacy Modules** → поддерживают обратную совместимость

### Точки интеграции:
- `main_new.py` - новая точка входа с постобработкой
- `main.py` - legacy точка входа (без постобработки)
- `config/settings.py` - централизованная конфигурация
- `core/data_models.py` - унифицированные модели данных
