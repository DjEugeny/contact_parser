## Технические детали

### Архитектура интеграции
```
LLM Response → LLMResponseValidator.validate_and_postprocess() → Validated & Processed Data
                     ↓
              [JSON Schema Validation]
                     ↓
              [PostProcessor Integration]
                     ↓
              [Graceful Degradation if needed]
```

### Ключевые возможности
1. **Валидация JSON Schema** - проверка структуры данных от LLM
2. **Постпроцессинг** - нормализация телефонов, дедупликация организаций
3. **Graceful Degradation** - корректная обработка невалидных данных
4. **Автокоррекция** - добавление обязательных полей при их отсутствии
