## Технические детали

### Структура схемы commercial_offers
```json
{
  "found": true/false,
  "offer_number": "string",
  "offer_date": "YYYY-MM-DD",
  "total_cost": number,
  "currency": "RUB",
  "end_user": "string",
  "intermediary": "string",
  "equipment_items": [
    {
      "name": "string",
      "model": "string",
      "quantity": number,
      "unit_price": number,
      "total_price": number
    }
  ],
  "reason": "string" // для случаев found: false
}
```

### Бизнес-правила валидации
1. Если `found: true`, обязательны поля: `offer_number`, `offer_date`, `total_cost`
2. Для найденных КП должен быть непустой список `equipment_items`
3. Сумма позиций должна соответствовать `total_cost` (допуск ±0.01)
4. Автоматическая нормализация валюты на "RUB"
