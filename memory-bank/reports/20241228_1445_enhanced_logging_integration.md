## Технические улучшения

### Категоризация производительности
- **OCR операции**: fast (<2s), normal (2-10s), slow (10-30s), very_slow (>30s)
- **Сжатие**: fast (<1s), normal (1-5s), slow (5-15s), very_slow (>15s)
- **Общие операции**: fast (<0.5s), normal (0.5-2s), slow (2-10s), very_slow (>10s)

### Метрики качества OCR
- Подсчет символов, слов, строк
- Анализ специальных символов и соотношения цифр
- Оценка структурированности текста
- Расчет среднего качества с весовыми коэффициентами

### Адаптивное логирование
- Медленные операции (>30s) → WARNING уровень
- Умеренно медленные (10-30s) → INFO уровень
- Быстрые операции (<10s) → DEBUG уровень
