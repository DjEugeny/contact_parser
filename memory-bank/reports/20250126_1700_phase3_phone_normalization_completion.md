## 🔧 Технические Детали

### Архитектура Интеграции

```
Email → OCR → LLM Extractor → PhoneNormalizer → Google Sheets Bridge → Google Sheets
                              ↑
                       Постобработка телефонов
```

### Ключевые Функции

1. **`normalize_contact_phone(phone: str) -> Dict[str, str]`**
   - Полная нормализация одного телефона
   - Возвращает все варианты нормализации
   - Расчет уверенности в корректности

2. **`normalize_contact_list(contacts: List[Dict]) -> List[Dict]`**
   - Пакетная обработка контактов
   - Обновляет контакты на месте
   - Добавляет нормализованные поля

3. **`_extract_extension(phone: str) -> Tuple[str, str]`**
   - Извлечение добавочных номеров
   - Поддержка различных форматов: доб., доп., ext., вн.

4. **`_detect_phone_type(normalized: str) -> str`**
   - Определение типа номера по кодам
   - Мобильные коды России: 910-989, 999

### Обработка Edge-Cases

- **Городские номера:** `(383) 285-25-10` → корректная обработка
- **Короткие номера:** `123-45-67` → валидация и обработка
- **С добавочными:** `+7 (495) 123-45-67 доб. 123` → разделение на основной + добавочный
- **Через запятую:** `+7(38822)6-43-63, 6-43-65` → поддержка из phone_extractor.py
