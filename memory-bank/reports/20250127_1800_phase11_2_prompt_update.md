### ✅ 2. Обновлена структура телефонов (п.6 мини-ТЗ)

**БЫЛО:** Поле `phone` как строка
```json
"phone": "+7(495) 640-17-71"
```

**СТАЛО:** Массив `phones` с типами
```json
"phones": [
  {
    "type": "main",
    "number": "+7(495) 640-17-71"
  }
]
```

**Поддерживаемые типы:** "main", "mobile", "office", "fax" или null

### ✅ 3. Добавлены строгие правила фильтрации КП (п.4 мини-ТЗ)

**Добавлен блок:**
```
⚠️ КРИТИЧЕСКИ ВАЖНО: Возвращай коммерческое предложение в массив "commercial_offers" ТОЛЬКО если:

✅ ВКЛЮЧАТЬ В commercial_offers:
- В письме/вложении явно присутствует оригинал КП от ООО "ДНК-Технология"
- Есть заголовок "Коммерческое предложение", "КП"
- Четко заполнены: total_cost, дата/номер КП, условия

❌ НЕ ВКЛЮЧАТЬ:
- Анкеты, заявки, документы "на ознакомление"
- Обсуждения без самого документа КП
- Закрывающие документы без КП
```

### ✅ 4. Обновлены инструкции по разделению контактов (п.2 мини-ТЗ)

**Для организаций:**
- Включать контактные данные БЕЗ привязки к конкретному человеку
- Если email/телефон указан без ФИО — относить к organizations
- Накапливать ВСЕ способы связи в массивы emails и phones

**Для персональных контактов:**

- Минимум: ФИО или (организация + должность) + способ связи
- Каждый контакт ОБЯЗАТЕЛЬНО должен иметь organization_id

### ✅ 5. Добавлены правила заполнения address и city (п.2, п.5 мини-ТЗ)

**Новое правило:**
```
📍 ОБЯЗАТЕЛЬНО заполняй поля "address" и "city":

- Если для контакта не указан — копируй из связанной организации
```
