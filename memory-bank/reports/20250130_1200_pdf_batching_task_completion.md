Реализованы следующие методы:

- `_process_pdf_with_batching`: Обработка с разбиением на батчи
- `_process_pdf_batch`: Обработка одного батча страниц
- `_process_single_pdf_page`: Обработка отдельной страницы с обработкой ошибок
