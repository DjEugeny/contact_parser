### 1. Двухуровневая система ключей

**Для контактов:**
```python
# Корпоративный email
("CONTACT", "EMAIL_GLOBAL", "user@company.com")  # Приоритет 1
("CONTACT", "EMAIL_IN_ORG", org_gid, "user@company.com")  # Алиас

# Личный email
("CONTACT", "EMAIL", org_gid, "user@gmail.com")  # Старая логика

# Телефон
("CONTACT", "PHONE_GLOBAL", "+79001234567")  # Приоритет 1
("CONTACT", "PHONE_IN_ORG", org_gid, "+79001234567")  # Алиас
```

**Для организаций:**
```python
("ORG", "INN", inn)  # Приоритет 1
("ORG", "DOMAIN", domain)  # Приоритет 2
("ORG", "NAME_CITY", name, city)  # Приоритет 3
("ORG", "NAME", name)  # Приоритет 4 (детерминированный!)
```
