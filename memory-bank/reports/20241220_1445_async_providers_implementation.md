## Технические детали

### Архитектура асинхронных провайдеров

```python
# Создание асинхронного менеджера
async_manager = AsyncProviderManager()

# Добавление провайдеров
async_manager.add_provider('openrouter', OpenRouterProvider())
async_manager.add_provider('groq', GroqProvider())

# Пакетное выполнение запросов
results = await async_manager.make_batch_requests_async(
    messages_list, 
    max_concurrent=2
)
```

### Система кеширования

**Ключевые особенности:**
- Многоуровневое кеширование (память + диск)
- TTL (время жизни) для записей кеша
- Автоматическая очистка устаревших записей
- Сжатие больших объектов

**Генерация ключей кеша:**
```python
cache_key = hashlib.md5(json.dumps({
    'messages': messages,
    'model': model,
    'kwargs': filtered_kwargs
}, sort_keys=True).encode()).hexdigest()
```

### Статистика производительности

**Отслеживаемые метрики:**
- Общее количество запросов
- Успешные/неудачные запросы
- Время выполнения запросов
- Попадания в кеш (cache hits)
- Промахи кеша (cache misses)
- Коэффициент попаданий в кеш
- Время ожидания в очереди
- Максимальная конкурентность
