### 0.3 Юнит-тесты для нормализации имён

**Приоритет**: P1  
**Время**: 2 часа  
**Статус**: ✅ Выполнено

**Результат**:

1. **Файл тестов**: `tests/unit/test_name_normalization.py`
   - **19 тестов**, все проходят ✅
   - Функция `norm_contact_name_smart()` встроена в файл тестов

2. **Покрытие тестов**:

   **Базовые тесты** (3):
   - Пустой ввод → None
   - Одно слово → lowercase
   - Фамилия первая → порядок сохраняется

   **Переставление имени/фамилии** (3):
   - Женские имена: Екатерина, Светлана, Ольга, Мария
   - Мужские имена: Алексей, Сергей, Дмитрий, Игорь
   - С отчеством: Екатерина Юрьевна, Светлана Александровна

   **Граничные случаи** (4):
   - Точки в инициалах → удаляются
   - Множественные пробелы → схлопываются
   - Смешанный регистр → lowercase
   - Неоднозначные имена (Ольга)

   **Реальные кейсы** (3):
   - Кондратюк Екатерина ↔ Екатерина Кондратюк
   - Воронова Светлана ↔ Светлана Воронова
   - Костюшева Евгения ↔ Евгения Костюшева

   **Стабильность** (2):
   - Идемпотентность (повторная нормализация)
   - Консистентность вариаций

   **Производительность** (1):
   - Обработка 300 имён

   **Дополнительное покрытие** (3):
   - Короткие слова (<=3 символа)
   - Различные окончания имён
   - Случаи без переставления

3. **Умная эвристика**:

   **Женские фамилии**: -ова, -ева, -ская, -цкая, -ских, -цких, -ына  
   **Мужские фамилии**: -ов, -ев, -ин, -ын, -ский, -цкий, -ой, -ый

   **Женские имена**: -а, -я, -ия, -ья, -на, -ла, -ра, -та, -да, -га, -ка, -ма, -са, -ва  
   **Мужские имена**: -ей, -ай, -ий, -рий, -ой, -уй, -ль, -нь, -рь, -ть, -дь, -сь, -ан, -он, -ен, -ег, -ур, -им, -ил, -ам

   **Особые случаи**:
   - `-ина`: длинные слова (>6) — имена (Екатерина), короткие — фамилии (Ильина)
   - `-ин`: контекст второго слова (Мартин Иванов → Мартин = имя)
   - `-ий`: контекст второго слова (Дмитрий Иванов → Дмитрий = имя)

**Запуск тестов**:
```bash
python -m pytest tests/unit/test_name_normalization.py -v
# ============================= 19 passed in 0.02s ==============================
```
