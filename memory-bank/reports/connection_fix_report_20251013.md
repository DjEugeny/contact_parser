# Отчет: Исправление проблемы подключения к почтовому серверу

**Дата:** 2025-10-13  
**Время:** 09:35 (UTC+7)  
**Версия кода:** Новая архитектура v2.0 с автоматическим переключением портов

## Проблема

При запуске EmailFetcher возникала ошибка `Connection reset by peer` при подключении к почтовому серверу `mail.dna-technology.ru` на порту 143 (IMAP+STARTTLS).

```
❌ Ошибка подключения (попытка 1): [Errno 54] Connection reset by peer
```

## Диагностика

Создана утилита `src/fetcher/utils/connection_diagnostic.py` для комплексной проверки подключения:

1. **TCP-соединение:** ✅ Порт 143 - доступен
2. **IMAP-соединение:** ❌ Порт 143 - сброс соединения сервером
3. **STARTTLS:** ❌ Порт 143 - сброс соединения сервером
4. **Альтернативный порт 993:** ✅ TCP-соединение установлено
5. **IMAP-соединение на 993:** ✅ Успешно
6. **Аутентификация на 993:** ✅ Успешно

**Вывод:** Сервер разрывает соединения на порту 143, но порт 993 (IMAPS) работает стабильно.

## Решение

### 1. Улучшен ConnectionManager

Добавлена автоматическая переключаемость между портами:

- **Основной порт:** 143 (IMAP+STARTTLS)
- **Резервный порт:** 993 (IMAPS)
- **Автоматическое переключение** при ошибке `Connection reset by peer`

```python
# Пробуем сначала основной порт, затем SSL порт если основной не работает
ports_to_try = [
    (IMAP_PORT, False, f"IMAP+STARTTLS на порту {IMAP_PORT}"),
    (IMAP_SSL_PORT, True, f"IMAPS на порту {IMAP_SSL_PORT}")
]
```

### 2. Обновлена конфигурация

Изменен `.env` файл:
```
IMAP_PORT=993  # Изменено на 993 (IMAPS) т.к. порт 143 не работает
```

### 3. Улучшена обработка ошибок

Добавлена специальная обработка для `ConnectionResetByPeer`:
- Автоматическое переключение на порт 993
- Детальное логирование процесса подключения
- Информативные сообщения о переключении

## Преимущества решения

1. **Автоматическая отказоустойчивость:** Система сама переключается на рабочий порт
2. **Обратная совместимость:** Сохранена поддержка обоих портов
3. **Информативное логирование:** Понятно, что происходит при подключении
4. **Без потери данных:** Все письма успешно обрабатываются

## Рекомендации

1. **Использовать порт 993 (IMAPS)** как основной для стабильности
2. **Сохранить автоматическое переключение** для отказоустойчивости
3. **Периодически проверять** работу порта 143 (возможно, временное ограничение)
