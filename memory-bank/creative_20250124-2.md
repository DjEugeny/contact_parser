## Описание проблем

При запуске `/Users/evgenyzach/contact_parser/src/api_pipeline_validator.py` на дате `2025-05-12` выявлены критические проблемы:

### 1. Проблемы логирования
- Логи записываются только в терминал
- Отсутствует запись в `/Users/evgenyzach/contact_parser/data/logs`
- Невозможно отследить историю выполнения

### 2. Дублирование OCR обработки
- Процесс повторно запускает OCR для уже обработанных файлов
- Результаты уже находятся в `/Users/evgenyzach/contact_parser/data/final_results/texts/2025-05-12`
- Неэффективное использование ресурсов

### 4. Сбои асинхронной обработки
- Из 12 писем все завершились ошибками
- LLM-провайдеры не получили данные для обработки
- Отсутствует финальный результат

### 5. Проблема больших вложений
- Файлы с объемом >15000 токенов неэффективны для LLM анализа
- Пример: `/Users/evgenyzach/contact_parser/data/attachments/test_documents/20250724_dna-technology_ru_ebe2f0bb_084400_attach_ТЗ по КТРУ по КП 8386.txt`

- Отсутствует фильтрация по размеру токенов
