# 📘 Настройки PreCleaner

Файл `precleaner.yaml` лежит рядом и управляет всеми эвристиками предочистки писем перед передачей в LLM. Ниже — краткое описание ключевых параметров и поведения ядра (`src/fetcher/utils/precleaner_core.py`).

## Основные пороги
- **`max_signature_lines` (по умолчанию 8)** — сколько непустых строк сохраняем у первой подписи отправителя. Если подпись длиннее, лишние строки удаляются.
- **`max_disclaimer_lines` (6)** — максимум непустых строк у первого дисклеймера. Всё, что ниже, обрезается.
- **`fold_quote_over_chars` (1200)** — цитаты длиннее указанного количества символов сворачиваются.
- **`fold_on_repeat` (true)** — повторные подписи/цитаты внутри треда сразу заменяются на плейсхолдеры.

## Цитаты (`quote_preview_*`)
- **`quote_preview_non_empty_lines` / `quote_preview_tail_non_empty_lines`** — сколько непустых строк брать с начала и конца цитаты перед плейсхолдером.
- **`quote_preview_header_markers`** — список заголовков (`From:`, `Sent:` и т.п.), которые всегда попадают в превью.
- **`quote_preview_min_lines`** — минимальное число непустых строк, при котором блок без `>` всё равно считается цитатой.
- **`quote_preview_markers`** — слова-триггеры (`" пишет"`, `"wrote:"`, `"forwarded message"` и др.), по которым выявляются цитаты без символов `>`.
- **`quote_preview_context_lines`** — дополнительный контекст рядом с найденными контактами (оставляем 0, чтобы не тянуть лишний текст).
- **`quote_preview_max_chars`** — максимальная длина превью блока; остаток заменяется пометкой `[quote snippet truncated]`.

## Подписи и дисклеймеры
- **`sig_markers`** — ключевые фразы/символы, по которым определяется подпись. Массив расширяем при появлении новых формулировок.
- **`disclaimer_markers`** — характерные строки дисклеймеров (рус/англ). Добавляем сюда новые паттерны, если заметили, что дисклеймер не распознаётся.
- **`keep_first_signature_per_sender` (true)** — первая подпись уникального отправителя сохраняется целиком (ограничена `max_signature_lines`). Все последующие подписи этого автора и внутри треда заменяются на плейсхолдер `[signature elided:…]`.
- **`keep_first_disclaimer_per_thread` (false)** — если включить, первый дисклеймер в треде будет обрезан до `max_disclaimer_lines` и оставлен, иначе сразу превращается в плейсхолдер.

### Как удаляются дубликаты подписей
1. Каждый выделенный блок подписи нормализуем и хэшируем (SHA-1 → 12 символов).
2. Хэш сохраняется в кэш треда и отправителя.
3. Первый экземпляр подписи остаётся (или обрезается), все последующие с тем же хэшем заменяются на `[signature elided:<email>#<hash>]`.

### Как обрезается дисклеймер
1. Блок классифицируется по маркерам из `disclaimer_markers`.
2. Первая часть (до `max_disclaimer_lines` непустых строк) сохраняется, остальное удаляется.
3. Добавляется запись в `clean_spans` с placeholder `[disclaimer truncated #<hash>]`.

## Рекомендации по настройке
- Если в письмах часто встречаются новые повторяющиеся подписи/дисклеймеры, добавляйте характерные строки в `sig_markers`/`disclaimer_markers`.
- Чтобы агрессивно схлопывать цитаты, уменьшайте `quote_preview_*` и `fold_quote_over_chars`.
- Для UX (например, чтобы показывать больше контекста в модерации) можно краткосрочно поднять `quote_preview_max_chars`.

Любые изменения конфигурации применяются без правок кода: достаточно обновить `precleaner.yaml` и перезапустить fetcher/pipeline.
