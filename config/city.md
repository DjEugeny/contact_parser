# Справочник городов России

Исходный перечень из Википедии преобразован в структурированный файл `config/russian_cities.csv`.

Файл содержит следующие поля:
- `city` — название города;
- `region_type`, `region` — тип и название субъекта Федерации;
- `federal_district` — федеральный округ;
- `capital_marker` — признак столицы региона (значение `2` — столица субъекта, `1` — районный центр);
- `population` — численность населения по переписи 2021 года;
- `timezone`, `geo_lat`, `geo_lon` — справочные атрибуты.

После очистки исключены графы «Герб», ссылки на гербы, сведения об основании и прежних названиях. Для удобства обработки сведения доступны в CSV.
