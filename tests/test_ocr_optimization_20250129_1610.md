## Проверяемые компоненты

### 1. Метод `_analyze_pdf_structure`
- Анализ структуры PDF для определения наличия текстового слоя
- Расчет соотношения текста к изображениям
- Определение embedded шрифтов
- Подсчет текстовых и графических объектов

### 2. Метод `_is_text_quality_good`
- Комбинированная оценка качества текста
- Интеграция структурного анализа PDF
- Улучшенная логика для документов с высоким structure_score

### 3. Метод `_analyze_page_quality`
- Детальный анализ качества текста на странице
- Проверка языка (русский/английский)
- Исключение технического мусора
- Анализ структурированного текста

## Технические улучшения

### 1. Производительность
- Анализ структуры PDF ограничен первыми 3 страницами
- Быстрая проверка на мусор перед детальным анализом
- Проверка первых 1000 символов для повторяющихся паттернов

### 2. Точность определения
- Комбинированный подход: структура PDF + текстовый анализ
- Специальные правила для документов с высоким structure_score
- Расширенные паттерны для обнаружения мусора

### 3. Языковая поддержка
- Поддержка кириллицы (коды 1040-1103) и латиницы
- Требование минимум 60% символов на известных языках
- Исключение файлов с >10% странных символов

### 4. Структурный анализ
- Определение embedded шрифтов для качественных PDF
- Расчет соотношения текста к изображениям
- Подсчет текстовых vs графических объектов

## Выявленные проблемы и решения

### Проблема 1: Ложные срабатывания на качественных PDF
**Решение:** Введена специальная логика для документов с structure_score ≥90, которая игнорирует строгие пороги при низком garbage_ratio (<5%)

### Проблема 2: Неэффективный анализ больших документов
**Решение:** Ограничение анализа структуры первыми 3 страницами, быстрые проверки перед детальным анализом

### Проблема 3: Неточное определение языка
**Решение:** Четкие диапазоны для кириллицы и латиницы, требование минимум 60% символов на известных языках
