## Цель теста
Проверить корректность интеграции улучшенных методов логирования в OCR процессор с метриками производительности и качества.

## Проверяемые компоненты
1. **Расширенные методы логирования**:
   - `_categorize_performance()` - категоризация производительности
   - `_get_file_size_mb()` - получение размера файла
   - `_log_ocr_quality_metrics()` - логирование метрик качества OCR
   - `_calculate_text_quality_score()` - расчет балла качества текста

2. **Интеграция в основные методы**:
   - `run_google_vision_ocr()` - основной метод Google Vision OCR
   - Метод с умным сжатием изображений

## Технические улучшения

### Расширенные метрики логирования:
- **Производительность**: Категоризация времени выполнения
- **Качество**: Балл качества текста (0-100)
- **Размер файла**: Автоматическое определение в МБ
- **Уверенность**: Средняя уверенность OCR
- **Метод**: Идентификация используемого OCR метода

### Структурированные данные логов:
```python
log_data = {
```
