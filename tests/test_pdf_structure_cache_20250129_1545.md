   - `_load_pdf_structure_cache()` - загрузка кэша из файла

   - Логирование использования кэша

## Технические особенности реализации

### Структура ключа кэша:
```python
key_string = f"{pdf_path.absolute()}_{pdf_path.stat().st_mtime}"
cache_key = hashlib.md5(key_string.encode()).hexdigest()
```

### Формат кэшированных данных:
```json
{
  "md5_hash": {
    "pages_count": 10,
    "text_objects_count": 150,
    "image_objects_count": 5,
    "font_types": ["Arial", "Times"],
    "has_embedded_fonts": true,
    "has_text_layer": true,
    "structure_score": 85,
    "text_confidence": 0.9
  }
}
```

### Логирование кэша:
- При загрузке: "Загружен кэш структуры PDF: X записей"
- При использовании: "Используется кэшированный результат анализа структуры PDF"
- При ошибках: соответствующие сообщения об ошибках

## Преимущества системы кэширования

1. **Производительность**: Избежание повторного анализа структуры PDF
2. **Надежность**: Кэш инвалидируется при изменении файла
3. **Персистентность**: Кэш сохраняется между запусками приложения
4. **Отказоустойчивость**: Обработка ошибок при работе с файловой системой
5. **Совместимость**: Преобразование типов данных для обратной совместимости
