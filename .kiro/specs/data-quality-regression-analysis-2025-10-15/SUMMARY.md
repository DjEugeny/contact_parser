## 🔥 Проблема в одном предложении

После рефакторинга Email Fetcher модуль `api_pipeline_validator.py` **не передаёт текст письма в LLM**, потому что ищет устаревшее поле `"body"`, которого больше нет в новой структуре данных.

---

## 📊 Последствия

- **text_length: 0** вместо 5490 символов
- **-70%** полноты имён контактов
- **-80%** извлечения должностей
- **-100%** извлечения телефонов и адресов
- **+50%** дублирования организаций

---

## 🎯 Корневая причина

**Файл:** `src/api_pipeline_validator.py`  
**Строка:** 670  
**Код:**
```python
body = email_data.get("body")  # ❌ Поле не существует в NEW fetcher
```

**Что происходит:**
1. NEW fetcher создаёт `body_raw` и `body_clean` (НЕТ `body`)
2. `api_pipeline_validator.py` ищет только `body` → `None`
3. Текст письма НЕ передаётся в LLM
4. LLM видит только вложения без контекста
5. Качество падает на 60-80%

---

## ✅ Решение

### Шаг 1: Исправить `api_pipeline_validator.py` (строка 670)

**Заменить:**
```python
body = email_data.get("body")
```

**На fallback логику:**
```python
# ✅ Поддержка NEW и LEGACY форматов
body_candidates = [
    email_data.get("body"),          # legacy
    email_data.get("body_clean"),    # NEW (приоритет)
    email_data.get("body_raw"),      # NEW (fallback)
]

body = None
for candidate in body_candidates:
    if candidate and isinstance(candidate, str) and candidate.strip():
        body = candidate
        break
```
