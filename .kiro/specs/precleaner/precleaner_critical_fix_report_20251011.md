## 🐛 Описание проблемы

### Что было обнаружено:

При детальном анализе результатов работы PreCleaner было выявлено, что система **не удаляла контент**, а только **добавляла метки обрезания** при обработке писем.

### Симптомы проблемы:

1. **Ложная статистика:** PreCleaner сообщал о сокращении 97-99% текста
2. **Полный контент сохранялся:** В `body_clean` оставался полный текст письма
3. **Добавлялись метки:** В конец текста добавлялись маркеры типа `[disclaimer truncated #hash]`
4. **Реальной экономии токенов не было:** LLM получал полный текст

### Пример проблемы:

**До исправления:**
```
body_clean: "Полный текст письма... [disclaimer truncated #8a77a19e9597]"
char_count: 647 (сообщалось о 97% сокращении)
```

**Фактически в файле:** Полный текст письма (~21,000 символов) + метка обрезания

## 🔍 Корневой анализ проблемы

### Местонахождение проблемы:
- **Файл:** [`src/fetcher/utils/precleaner_core.py`](src/fetcher/utils/precleaner_core.py:154-161)
- **Функция:** Обработка подписей и дисклеймеров
- **Строки:** 154-161

### Проблемный код:
```python
trimmed = "\n".join(lines[:max_signature_lines])
if len(lines) > max_signature_lines:
    marker = f"[{block.kind} truncated #{fingerprint}]"
    trimmed += f"\n{marker}"  # 🔥 ПРОБЛЕМА: метка добавляется, но текст НЕ удаляется!
```

**Ошибка:** Вместо удаления длинных подписей/дисклеймеров, код просто добавлял метку обрезания в конец текста, оставляя весь контент нетронутым.

## 🛠️ Исправление проблемы

### Изменения в коде:

**Файл:** [`src/fetcher/utils/precleaner_core.py`](src/fetcher/utils/precleaner_core.py:145-165)

**До исправления:**
```python
trimmed = "\n".join(lines[:max_signature_lines])
if len(lines) > max_signature_lines:
    marker = f"[{block.kind} truncated #{fingerprint}]"
    trimmed += f"\n{marker}"  # Полный текст сохраняется
    spans.append({"placeholder": marker, "hash": fingerprint, "kind": block.kind})
cleaned_chunks.append(trimmed)
```

**После исправления:**
```python
trimmed = "\n".join(lines[:max_signature_lines])
if len(lines) > max_signature_lines:
    # Сохраняем только первые строки, остальное полностью удаляем
    trimmed = "\n".join(lines[:max_signature_lines])
    marker = f"[{block.kind} truncated #{fingerprint}]"
    cleaned_chunks.append(trimmed)  # Убираем marker из контента!
    spans.append({"placeholder": marker, "hash": fingerprint, "kind": block.kind})
else:
    # Короткие блоки сохраняем полностью
    cleaned_chunks.append(block.text)
```

### Дополнительные улучшения:

Также исправлена обработка цитат для полного удаления длинных повторяющихся цитат.
