## 🔧 Конфигурация PreCleaner

Основной файл конфигурации: [`config/precleaner.yaml`](config/precleaner.yaml:1)

### Ключевые параметры:
- **remove_disclaimers**: Удаление дисклеймеров
- **remove_long_quoting**: Удаление длинных цитат
- **remove_duplicated_signatures**: Удаление дублированных подписей
- **max_quoted_lines**: Максимум строк цитирования
- **max_signature_length**: Максимальная длина подписи

### Добавление новых паттернов:
```yaml
disclaimer_patterns:
  - "ВАШ НОВЫЙ ДИСКЛЕЙМЕР"
```
