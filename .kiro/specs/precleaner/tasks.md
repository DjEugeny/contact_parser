## ⚠️ Риски и наблюдения
- Потеря переносов может быть связана с plain/text источником, а не HTML-очисткой — требуется подтверждение по сырым письмам.
- Агрессивные placeholder’ы делают LLM-этап слепым к контактам; изменения нужно тестировать на реальных данных перед отключением дедупликации.
- Профилизация «юридических» писем не планируется: акцент на лабораторной переписке и адаптации по длине/наличию цитат без тематических классификаторов.

- `config/precleaner.yaml` — текущие настройки

- `src/fetcher/utils/precleaner_core.py` — логика фолдинга цитат и подписей
- `scripts/test_precleaner_improvements.py`, `scripts/test_precleaner_simple.py` — стартовые точки для регрессионных тестов
- `run_new_fetcher.py` — стартовая точка для запуска нового Fetcher
