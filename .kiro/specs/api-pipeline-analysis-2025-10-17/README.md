### 2. [CHUNKING_AND_CONTEXT_ANALYSIS.md](./CHUNKING_AND_CONTEXT_ANALYSIS.md)
**Анализ системы chunking и контекстного окна**

**Ключевые находки:**
- ⚠️ Лимит 15K токенов применяется к **СУММАРНОМУ тексту** (неправильно!)
- ✅ Правильно: лимит должен быть на **ОТДЕЛЬНЫЕ ВЛОЖЕНИЯ**
- ⚠️ Конфигурация chunking оптимизирована для DeepSeek (128K), НЕ для Gemini
- ⚠️ Фильтр больших вложений реализован **НЕПРАВИЛЬНО**

**Модель LLM:**
```yaml
google/gemini-2.0-flash-001
  context_window: 1,000,000 токенов (1M)
  приоритет: 1 (основная модель)
  приватность: НЕ публикует данные ✅
```

**Существующий chunker:**
- ✅ Полнофункциональный модуль `src/core/chunker.py`
- ✅ Токен-ориентированное разбиение
- ✅ Автокоррекция размера чанков
- ❌ НЕ оптимизирован под Gemini 2.0 Flash

**Решения:**
- ✅ Исправить логику фильтра: лимит 15K на **ОТДЕЛЬНЫЕ** вложения
- ✅ Увеличить лимит для ВСЕГО письма до 800K (для Gemini)
- ✅ Обновить конфигурацию chunking под Gemini
- ✅ Реализовать model-aware chunking
