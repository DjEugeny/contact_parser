### Исходные данные:
- **Промпт:** 30,000 символов
- **Письмо:** 80,000 символов  
- **Вложения:** 3 штуки с OCR (~15,000 символов)
- **Итого текста:** ~125,000 символов
- **Модель:** Google Gemini Flash 2.0 (1,000,000 токенов контекстное окно)

## 🧮 Расчёт таймаута

### Шаг 1: Базовый расчёт

```python
from src.utils.timeout_calculator import calculate_dynamic_timeout

timeout = calculate_dynamic_timeout(
    text_length=125000,           # Весь текст
    attachments_count=3,          # 3 вложения
    has_ocr=True,                 # Есть OCR
    model_context_window=1000000  # Gemini Flash 2.0
)
```

### Шаг 2: Компоненты таймаута

```
Базовый таймаут:        60 секунд
Текст (125,000 / 1000): +125 секунд
Вложения (3 * 30):      +90 секунд
OCR:                    +30 секунд
─────────────────────────────────
Итого:                  305 секунд
```

### Шаг 3: Применение максимума

**Без учёта модели:**
- Максимум: 300 секунд (5 минут)
- **Результат: 300 секунд** ❌ Может быть недостаточно!

**С учётом модели (обновлённая версия):**
- Модель с контекстом > 100k токенов
- Максимум увеличен до: 600 секунд (10 минут)
- **Результат: 345 секунд (5 минут 45 секунд)** ✅

## 🔄 Как работает retry с увеличением таймаута

Если первая попытка не успеет, система автоматически повторит с увеличенным таймаутом:

### Попытка 1:
- Таймаут: **345 секунд** (5 мин 45 сек)
- Если таймаут → переход к попытке 2

### Попытка 2:
- Таймаут: **345 * 1.5 = 517 секунд** (8 мин 37 сек)
- Увеличение на 50%
- Задержка перед попыткой: 2 секунды

### Попытка 3:
- Таймаут: **517 * 1.5 = 775 секунд** (12 мин 55 сек)
- Но ограничен максимумом: **600 секунд** (10 минут)
- Задержка перед попыткой: 4 секунды

## 📍 Где применяется таймаут

### 1. В провайдерах (OpenRouter, Replicate, Groq)

```python
# src/providers/openrouter.py
async with session.post(
    self.config.base_url,
    json=payload,
    headers=self.config.headers,
    timeout=aiohttp.ClientTimeout(total=calculated_timeout)  # ← Здесь!
) as response:
    ...
```

### 2. В config_manager.py

```python
# src/config/config_manager.py
async def make_request_async(self, provider, request_data, request_id=None):
    # Рассчитываем динамический таймаут
    timeout = calculate_dynamic_timeout(
        text_length=len(request_data.get('text', '')),
        attachments_count=len(request_data.get('attachments', [])),
        has_ocr=request_data.get('has_ocr', False),
        model_context_window=provider.context_window  # ← Новый параметр
    )
    
    # Применяем retry с этим таймаутом
    response = await retry_with_backoff_async(
        self._execute_provider_request,
        provider=provider,
        request_data=request_data,
        initial_timeout=timeout  # ← Здесь применяется!
    )
```

### 3. В HTTP клиенте

## 🔧 Рекомендации для очень больших писем

### Если письмо > 100,000 символов:

1. **Используйте модели с большим контекстом:**
   - ✅ Google Gemini Flash 2.0 (1M токенов)
   - ✅ Claude 3 Opus (200k токенов)
   - ✅ GPT-4 Turbo (128k токенов)

2. **Передавайте информацию о модели:**
```python
provider_config = {
    'name': 'Gemini',
    'model': 'gemini-2.0-flash-exp',
    'context_window': 1000000  # ← Важно!
}
```

3. **Настройте максимальный таймаут:**
```python
# Для очень больших писем можно увеличить
timeout = calculate_dynamic_timeout(
    text_length=125000,
    attachments_count=3,
    has_ocr=True,
    max_timeout=900,  # 15 минут для особых случаев
    model_context_window=1000000
)
```

4. **Используйте chunking для экстремально больших писем:**
   - Если письмо > 200,000 символов
   - Разбивайте на части по 100,000 символов
   - Обрабатывайте части параллельно
