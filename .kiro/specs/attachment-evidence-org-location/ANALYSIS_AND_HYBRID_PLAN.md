### ✅ Вопрос 2: Как объединяется текст письма и вложений?

**Найдено в коде:**

#### В `src/api_pipeline_validator.py` (метод `_compose_combined_text`):
```python
def _compose_combined_text(self, email_data: Dict[str, Any], date: str) -> str:
    parts: List[str] = []
    body = email_data.get("body")
    if body:
        parts.append(f"=== ТЕКСТ ПИСЬМА ===\n{body}")
    
    for index, attachment in enumerate(attachments, start=1):
        if attachment_text:
            name = attachment.get("original_filename") or ...
            parts.append(f"\n=== ВЛОЖЕНИЕ {index}: {name} ===\n{attachment_text}")
    
    return "\n\n".join(parts)
```

#### В `src/ocr_processor_adapter.py`:
```python
combined_text = f"ТЕМА: {email.get('subject', '')}\n"
combined_text += f"ОТ: {email.get('from', '')}\n"
...
combined_text += "=" * 50 + "\n\n"
combined_text += email_text

if relevant_attachments:
    combined_text += "\n\n" + "=" * 50 + "\n"
    combined_text += "СОДЕРЖИМОЕ ВЛОЖЕНИЙ:\n"
    combined_text += "=" * 50 + "\n\n"
    
    for i, attachment in enumerate(relevant_attachments, 1):
        combined_text += f"--- ВЛОЖЕНИЕ {i}: {attachment['file_name']} ---\n"

```

**Структура текста, который видит LLM:**
```
=== ТЕКСТ ПИСЬМА ===
[текст письма]

=== ВЛОЖЕНИЕ 1: Ком.пред.14.03.2025 для Москва Компания МИЛЛАБ для Абакан ЦГиЭ.pdf ===
[текст вложения]
```

**Вывод:** Есть четкие разделители! LLM может понять, где письмо, а где вложение.

### Фаза 2: Защита от мусора (ДОПОЛНЕНИЕ) 🛡️

**Цель:** Предотвратить добавление мусорных данных постобработкой

**Проблемы для решения:**
1. Не извлекать только индекс ("117587") как адрес
2. Не применять обогащение с низкой уверенностью
3. Не перезаписывать данные, заполненные LLM

**Действия:**

#### 2.1. Фильтр "только индекс"

#### 2.2. Повышение порога уверенности
```python
# В src/postprocessing/attachment_evidence_extractor.py
# Метод _calculate_confidence

def _calculate_confidence(self, org_info, location_info, attachment):
    confidence = 0.6
    
    # Если только адрес без города - снижаем уверенность
    if location_info.get('address') and not location_info.get('city'):
        confidence *= 0.5  # Снижаем до 0.3
    
    # Если адрес очень короткий - снижаем уверенность
    if location_info.get('address') and len(location_info['address']) < 20:
        confidence *= 0.7
    
    return min(1.0, confidence)
```
