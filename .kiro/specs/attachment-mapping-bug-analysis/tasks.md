# План задач по исправлению проблемы с вложениями

## 📋 Обзор

Этот документ содержит детальный план задач по исправлению критического бага с сопоставлением вложений в системе email-обработки.

**Проблема**: вложения из одного письма в thread цепочке некорректно приписываются другим письмам в той же цепочке.

**Корневая причина**: система использует `thread_id` вместо `message_id` для определения принадлежности вложений.
