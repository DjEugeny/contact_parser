## 📋 Краткое описание

Реализован модуль для автоматического обогащения организаций email-адресами из заголовков письма, подписей и вложений с интеллектуальной классификацией на роль/общие vs персональные адреса.

## 🚀 Основные результаты

- ✅ **Создан:** `/src/postprocessing/org_email_enricher.py` (448+ строк)
- ✅ **Функции:**
  - Извлечение из заголовков письма (From, To, Cc, Reply-To)
  - Парсинг подписи письма с регулярками
  - Обработка OCR-текста вложений
  - Классификация роль/общие vs персональные адреса

## 🔧 Технические характеристики

### Алгоритм классификации:
```python
# Роль/общие адреса (whitelist)
ROLE_EMAIL_PREFIXES = {
    'info', 'mail', 'sales', 'office', 'contact', 'support', 'admin', 
    'order', 'service', 'pr', 'hr', 'marketing', 'accounting', 'billing',
    'tender', 'export', 'import', 'help', 'it', 'hello', 'welcome'
}

# Персональные индикаторы (blacklist)
- Домены: gmail.com, yahoo.com, mail.ru, yandex.ru
- Паттерны: firstname.lastname@, f.lastname@, имя+цифры
```

### Структура метаданных:
```json
"postprocessing_metadata": {
  "org_email_enrichment": {
    "<org_gid>": {
      "added": ["mail@medcongress.ru"],
      "skipped": ["ivan.petrov@medcongress.ru"],
      "source": {"mail@medcongress.ru": "headers"}
    }
  }
}
```
