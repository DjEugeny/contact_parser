### 1. Структурированное логирование переключений моделей

Добавлено **двойное логирование** для удобства:

#### 📝 Текстовый лог (для человека)
- **Файл:** `data/logs/model_fallback.log`
- **Формат:** Читаемый текст с разделителями
- **Содержит:**
  - Timestamp
  - Провайдер
  - Старая и новая модель (с приоритетами)
  - Тип ошибки
  - Сообщение об ошибке
  - Детали (input_length, response_length, estimated_tokens, etc.)

**Пример:**
```
======================================================================
🔄 ПЕРЕКЛЮЧЕНИЕ МОДЕЛИ
======================================================================
Провайдер:    openrouter
Старая модель: google/gemini-2.0-flash-exp:free (priority 2)
Новая модель:  qwen/qwen-2.5-72b-instruct:free (priority 3)
Тип ошибки:   empty_response
Сообщение:    Empty response from model
Детали:
  - input_length: 15234
  - response_length: 0
  - request_id: abc123
```

#### 📊 JSON лог (для анализа)
- **Файл:** `data/logs/model_fallback.jsonl`
- **Формат:** JSONL (JSON Lines) - каждая строка это отдельный JSON объект
- **Содержит:** Те же данные в структурированном формате

**Пример:**
```json
{"timestamp": "2025-10-09T15:30:45.123456", "event_type": "model_switch", "provider": "openrouter", "old_model": "google/gemini-2.0-flash-exp:free", "old_model_priority": 2, "new_model": "qwen/qwen-2.5-72b-instruct:free", "new_model_priority": 3, "error_type": "empty_response", "error_message": "Empty response from model", "details": {"input_length": 15234, "response_length": 0, "request_id": "abc123"}}
```

#### 🔄 Log Rotation
- **Максимальный размер файла:** 10 MB
- **Количество backup файлов:** 5
- Автоматическая ротация при достижении лимита

### 2. Детальная классификация ошибок

Добавлены типы ошибок (`error_type`):
- `rate_limit` - Rate limit от API
- `empty_response` - Пустой ответ от модели
- `context_length` - Превышение context window
- `data_policy` - Ошибка политики данных (OpenRouter)
- `model_not_found` - Модель не найдена
- `model_error` - Общая ошибка модели
- `provider_error` - Критическая ошибка провайдера
