## 💡 Ключевые особенности реализации

### 1. **Интеллектуальная система scoring**
Многофакторная модель учитывает:
- Корпоративную принадлежность (email домен)
- Профессиональный контекст (должность, роль)
- Географическое соответствие (город)
- Ценность контакта (value_score)

### 2. **Гибкая конфигурация**
Три режима работы:
- **Conservative:** Высокие требования к confidence
- **Balanced:** Стандартные пороги (по умолчанию)
- **Aggressive:** Низкие пороги для максимального обогащения

### 3. **Безопасность данных**
- Исключение персональных мобильных номеров
- Фильтрация только корпоративных типов
- Приоритет человеческой разметки (LLM) над автоматикой

### 4. **Прозрачность операций**
- Детальные метаданные каждого решения
- Статистика по причинам пропуска
- Полное логирование для отладки
