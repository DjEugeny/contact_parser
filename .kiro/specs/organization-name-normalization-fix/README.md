# Исправление нормализации названий организаций

## 📋 Обзор проекта

Данная папка содержит полную документацию по исправлению нормализации названий организаций в системе обработки данных. Основная проблема заключалась в том, что юридические формы (например, "ООО") не удалялись из названий организаций.

## 📋 Поддерживаемые юридические формы

### Российские формы (удаляются)
ООО, ЗАО, ОАО, ПАО, АО, ФБУЗ, ГБУЗ, ФГБУ, ФГУП, ГУП, МУП, НКО

### Международные формы (удаляются)
LLC, LTD, INC

### Особый случай (сохраняется)
**ИП** - индивидуальный предприниматель
