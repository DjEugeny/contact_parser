```python
def _normalize_organization_name(self, name: str) -> str:
    """Нормализация названия организации
    
    Args:
        name: Исходное название
        
    Returns:
        str: Нормализованное название
    """
    if not name:
        return ''
    
    # Убираем лишние пробелы
    normalized = ' '.join(name.strip().split())
    
    # Убираем юридические формы (кроме ИП - для них префикс важен)
    legal_forms = [
        'ООО', 'ЗАО', 'ОАО', 'ПАО', 'АО', 'ФБУЗ', 'ГБУЗ', 
        'ФГБУ', 'ФГУП', 'ГУП', 'МУП', 'НКО', 'LLC', 'LTD', 'INC',
        'ооо', 'зао', 'оао', 'пао', 'ао', 'фбуз', 'гбуз',
        'фгбу', 'фгуп', 'гуп', 'муп', 'нко', 'llc', 'ltd', 'inc'
    ]
    
    words = normalized.split()
    
    # Специальная обработка для ИП - приводим к правильному регистру
    if words and words[0].lower() == 'ип':
        words[0] = 'ИП'
        normalized = ' '.join(words)
    # Удаляем юридические формы в начале названия (кроме ИП)
    elif words and words[0] in legal_forms:
        words = words[1:]
        normalized = ' '.join(words)
    
    # Убираем кавычки (парные) для всех случаев
    quote_pairs = [('«', '»'), ('"', '"'), ("'", "'")]
    
    # Сначала проверяем кавычки вокруг всей строки
    for open_quote, close_quote in quote_pairs:
        if normalized.startswith(open_quote) and normalized.endswith(close_quote):
            normalized = normalized[len(open_quote):-len(close_quote)].strip()
            break
    
    # Затем убираем кавычки вокруг отдельных слов
    words = normalized.split()
    cleaned_words = []
    for word in words:
        cleaned_word = word
        for open_quote, close_quote in quote_pairs:
            if cleaned_word.startswith(open_quote) and cleaned_word.endswith(close_quote):
                cleaned_word = cleaned_word[len(open_quote):-len(close_quote)]
                break
        cleaned_words.append(cleaned_word)
    
    normalized = ' '.join(cleaned_words)
    
    # Применяем нормализацию первого слова (если это не ИП)
    if normalized and not normalized.startswith('ИП '):
        normalized = normalize_first_word_only(normalized)
    
    return normalized
```

## Алгоритм работы функции

### 1. Предварительная обработка
- Проверка на пустое значение
- Удаление лишних пробелов

### 2. Обработка юридических форм
```
Вход: "ООО Экомед"
├── Разбиение на слова: ["ООО", "Экомед"]
├── Проверка первого слова: "ООО" в legal_forms
├── Удаление юридической формы: ["Экомед"]
└── Результат: "Экомед"
```

### 3. Специальная обработка ИП
```
Вход: "ип иванов"
├── Проверка первого слова: "ип".lower() == "ип"
├── Исправление регистра: "ИП"
└── Результат: "ИП иванов"
```

### 4. Удаление кавычек
```
Этап 1 - Кавычки вокруг всей строки:
"«Экомед»" → "Экомед"

Этап 2 - Кавычки вокруг отдельных слов:
"ИП \"Иванов\"" → "ИП Иванов"
```

### 5. Финальная нормализация
- Применение `normalize_first_word_only()` для не-ИП
- Приведение первой буквы к заглавной
