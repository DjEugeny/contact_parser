### Симптом

## 🔍 Root Cause Analysis

### Код в `src/postprocessing/postprocessor.py` (строки 786-790)

**Было**:
```python
for contact in contacts:
    org_id = contact.get('organization_id')
    org_gid = org_gid_lookup.get(org_id)
    if not org_gid:
        continue  # ❌ Пропускаем контакт без org_gid
```

**Проблема**:
1. Если `organization_id: null`, то `org_gid_lookup.get(None)` возвращает `None`
2. Проверка `if not org_gid:` пропускает контакт
3. Контакт не получает `gid`

### Поддержка в `src/registry/global_registry.py`

**Хорошая новость**: Реестр УЖЕ поддерживает контакты без организации!

```python
def iter_contact_keys(contact: Dict[str, Any], org_gid: Optional[str]) -> Iterable[Tuple[str, ...]]:
    # Для контактов без организации используем специальный маркер
    org_key = org_gid if org_gid is not None else "PERSONAL"  # ✅
    
    email = norm_email(contact.get("email"))
    if email:
        key = ("CONTACT", "EMAIL", org_key, email)  # ← org_key = "PERSONAL"
        yield key
```

**Вывод**: Нужно просто передать `org_gid=None` в `resolve_contact()`, и реестр создаст ключ с маркером `"PERSONAL"`.

## ✅ Реализованное исправление

### Файл: `src/postprocessing/postprocessor.py`

**Изменения в методе `_assign_global_ids()` (строки 786-811)**:

```python
# Было:
for contact in contacts:
    org_id = contact.get('organization_id')
    org_gid = org_gid_lookup.get(org_id)
    if not org_gid:
        continue  # ❌ Пропускаем
    
    result = self.gid_registry.resolve_contact(contact, org_gid)
    contact['gid'] = result.gid
    gid_assignments.append({
        'entity': 'contact',
        'local_id': contact.get('contact_id'),
        'organization_id': org_id,
        'organization_gid': org_gid,
        'gid': result.gid,
        ...
    })

# Стало:
for contact in contacts:
    org_id = contact.get('organization_id')
    # ✅ Для контактов без организации используем org_gid=None (маркер PERSONAL)
    org_gid = org_gid_lookup.get(org_id) if org_id is not None else None
    
    try:
        result = self.gid_registry.resolve_contact(contact, org_gid)
    except ValueError:
        continue
    contact['gid'] = result.gid
    
    assignment_entry = {
        'entity': 'contact',
        'local_id': contact.get('contact_id'),
        'gid': result.gid,
        'match_rule': result.match_rule,
        'key_tuple': list(result.key_tuple),
        'alias_added': result.alias_added,
        'source': result.source,
    }
    # ✅ Добавляем organization_id и organization_gid только если есть организация
    if org_id is not None:
        assignment_entry['organization_id'] = org_id
        assignment_entry['organization_gid'] = org_gid
    
    gid_assignments.append(assignment_entry)
```

### Ключевые изменения:

1. **Убрана проверка `if not org_gid: continue`**
   - Теперь обрабатываются ВСЕ контакты

2. **Условное назначение `org_gid`**
   ```python
   org_gid = org_gid_lookup.get(org_id) if org_id is not None else None
   ```
   - Если `organization_id: null` → `org_gid = None`
   - Если `organization_id: 1` → `org_gid = "58a49494-..."`

3. **Условное добавление полей организации в metadata**
   ```python
   if org_id is not None:
       assignment_entry['organization_id'] = org_id
       assignment_entry['organization_gid'] = org_gid
   ```
   - Для контактов без организации не добавляем `organization_id` и `organization_gid` в metadata
