# Design — Phone Ownership Disambiguation

## Контекст
- LLM иногда переносит телефоны между организациями (пример: `email_019…` — у «ДНК-Технология» оказались номера «МЕД КОНГРЕСС»).
- Постпроцессор сейчас только нормализует телефон, но не проверяет принадлежность.
- Требуется многоуровневая защита: эвристики + обновлённый промпт + ручные overrides.

## Архитектурный план
1. **PostProcessor**
   - Добавить этап `resolve_phone_conflicts` после `_cleanup_organization_emails` и до `_assign_global_ids`/normalizer.
   - На вход: словарь организаций, список контактов.
   - На выход: очищенные телефоны + `metadata['phone_conflicts']` (resolved/unresolved).

2. **Эвристики**
   - Группировать телефоны → набор организаций.
   - Оценка «принадлежности»: приоритет — код города/город → домен → контакты.
   - Если один владелец набрал максимальный вес с запасом — оставить номер только у него, убрать у других.
   - При равенстве весов ничего не меняем, фиксируем конфликт `status="unresolved"`.

3. **Метаданные**
   - `postprocessing_metadata['phone_conflicts'] = {'resolved': [...], 'unresolved': [...]}`
   - Каждый элемент: `{'phone': '+7...', 'status': 'resolved', 'kept_gid': '...', 'removed_gids': [...], 'reason': 'city_match'}`.

4. **Промпт**
   - Дополнить правилами «не переносить HQ телефоны между компаниями» + примером с `+7 (383)`.

5. **Overrides**
   - `registry/phone_overrides.jsonl` (или YAML), чтобы вручную закрепить телефон за организацией.
   - Тул health-check должен выявлять коллизии и предлагать overrides.

## Поток данных
```
LLM → PostProcessor
  ↳ dedup org/contacts
  ↳ cleanup emails
  ↳ resolve_phone_conflicts  ← новые эвристики
  ↳ assign_global_ids
  ↳ backfill / enrich / normalize
  ↳ build_final_result (metadata)
```

## Альтернативы
- Запрашивать у LLM «source organization» для каждого телефона. Минусы: удорожание и всё равно возможны ошибки.
- Убирать повторяющиеся телефоны «вручную» (анализ CSV) — не масштабируется.

## Тестирование
- Юнит: телефон у двух организаций → остаётся у той, где совпал город/домен; при равенстве ничего не удаляем.
- Интеграция: письма 018/019 → «МЕД КОНГРЕСС» получает свои номера.
- Regression: pipeline прогон — `phone_conflicts` заполняется.
