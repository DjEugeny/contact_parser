### 1. ✅ Исправление AsyncProviderWrapper

**Проблема:** AsyncProviderWrapper пытался вызвать синхронный метод `make_request` у провайдеров через `run_in_executor`, но провайдеры имеют асинхронный метод.

**Решение:** 
```python
# Было:
result = await loop.run_in_executor(
    self.executor,
    self.provider.make_request,
    prompt,
    **kwargs
)

# Стало:
request_data = {
    'messages': [{'role': 'user', 'content': prompt}],
    **kwargs
}
result = await self.provider.make_request(request_data, **kwargs)
```
